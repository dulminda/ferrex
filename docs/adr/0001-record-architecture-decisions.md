# ADR 0001: Record architecture decisions

**Status:** Accepted

## Context
Design trade-offs (data structures, threading model, memory orders) are the
most valuable part of this project and the easiest to forget.

## Decision
Every significant decision gets a short ADR in `docs/adr/NNNN-title.md` with
Context, Decision, Consequences, and Alternatives considered.

## Consequences
A small amount of writing per phase; a clear record for reviewers and interviews.
